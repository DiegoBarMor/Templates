# Raylib Template
1) Run `scripts/install_raylib.sh` the first time this template is used.
2) Compile the project anytime by running `scripts/compile_project.sh`
3) Run `scripts/prepare_test.sh` to set up an external directory for building and testing the project. This will re-create the directory, copy the `scripts/compile_project.sh` and copy the `assets` directory (if present).
4) Use `scripts/run_test.sh` for building and testing the project.
